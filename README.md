# boostcell

Boost color cell values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/boostcell/

## Install / run

```bash
git clone https://github.com/theworker02/boostcell.git
cd boostcell
node src/cli.js
node --test
```
